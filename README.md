# SmartControl Background Library

Remote media library for the SmartControl BYD Background tab.

- Wallpapers are 1907x720 PNG assets sized for wide BYD/DiLink displays.
- Motion backgrounds are short, muted 1920x720 H.264 MP4 loops.
- `catalog.json` is the application-facing manifest.
- Large media is published under the GitHub release tag `background`, keeping it out of the SmartControl APK.

The motion backgrounds are animated derivatives of wallpaper assets already owned and published in this repository.
